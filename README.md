# Saltline · 自由混战

基于原版 Saltline 港口 FPS 改造的浏览器多人游戏，保留原地图、枪械动画、程序化材质、雨景和音效。

## 启动

需要 Node.js 22 或更新版本。在本目录运行：

```sh
npm ci
npm start
```

也可以在 macOS 双击 `启动游戏.command`。默认地址 http://localhost:18453 。服务器使用 `0.0.0.0` 监听，可用 `PORT=8080 npm start` 更换端口。

1. 输入呼号，点击“创建房间”。
2. 朋友打开同一台服务器的地址，输入 6 位房间码加入。
3. 至少 2 人，由房主开始；最多 4 人。
4. 每局 5 分钟，击杀最多者获胜，同分并列。死亡后 3 秒复活，复活保护 2 秒，开枪立即解除保护。
5. 本局结束后由房主“再来一局”。

操作：WASD 移动，鼠标瞄准，左键开火，右键开镜，R 换弹，Space 跳跃，Shift 冲刺，C 蹲下，Tab 战绩。Esc 释放鼠标，比赛仍继续。浏览器无法锁定鼠标时保留原版拖动/鼠标移动瞄准方式。大厅可调整画质。备用弹药无限，每匣 30 发，伤害 26，保留原版后坐力与散布。

## 两台电脑怎样连接

同一局域网中，朋友使用服务器电脑的局域网 IP，例如 `http://服务器IP:18453`，而不是自己的 localhost。需要网络允许访问该端口。复制邀请链接时，地址栏应当已使用朋友可访问的服务器地址。

公网游玩需要一台能够持续运行 Node.js 的主机，并通过 HTTPS 反向代理同时转发网页与 `/ws` 的 WebSocket 升级请求。这个项目不能只上传静态 HTML 就实现联机。当前没有部署到公网，也未验证跨公网网络条件。

服务器重启会清空房间和战绩。断线后页面提示重新连接，刷新后重新加入；进行中的房间暂不支持中途加入或断线恢复。第一版没有账号、持久化排行、匹配队列、聊天或观战系统。

## 实现与验证

- `public/index.html`：原版程序化场景和渲染代码，仅改造引导入口；固定地图种子 4207。
- `public/client.js`、`public/pvp.css`：房间 UI、联机适配、远端角色、预测与位置校正。
- `server/match.js`：服务器对局规则、弹药、命中、计分和复活。
- `server/physics.js`、`server/map.json`：服务器移动与碰撞，557 个原版碰撞盒和 38 个候选出生点。
- `server/index.js`：HTTP、WebSocket、房间隔离、心跳与消息限流。
- `tests/`：规则及真实双 WebSocket 集成测试；`browser-fixture.js` 仅用于受控浏览器验收，不由 `npm start` 启动。
- `docs/verification.md`：实测范围和截图。

```sh
npm test
```

服务器根据玩家输入计算移动、重力和碰撞，客户端预测操作，远端插值。服务器计算射线命中与遮挡，客户端不能上报伤害或目标。第一版未实现延迟回溯和竞技级反作弊；高延迟下命中与位置校正仍需实网调优。远端人物是新增的程序化简化模型。

原始游戏来源：https://pages.eiaserinnys.me/d/saltline-fable52 。下载原件保留在本项目上级的 `saltline-fable52.html`。字体仍使用原页面的 Google Fonts；字体网络不可用时使用系统字体。

## 文字自定义角色

大厅点击“自定义角色”，对局中点击“角色外观”：输入 2—300 字描述 → 生成三维预览 → 拖动查看 → 点击“装备这个角色”。其他玩家随后看到同一个外观；可随时恢复默认外观。最近 5 个生成结果及装备选择保存在当前浏览器，下次刷新可恢复。没有图片上传入口。

AI 返回受限的几何结构数据，程序生成曲线触手、装甲、毛发、鳞片等细节；渲染器没有针对物种的预设。生成结果仍可能与描述有偏差，需玩家预览确认。当前自定义角色支持整体移动、朝向与蹲下缩放，尚未实现任意肢体的独立行走和持枪动画。角色统一归一到 1.8 米高；外形宽度可以不同，但服务器命中、移速和伤害仍沿用统一规则。

启动 AI 功能（密钥只配置在服务器端）：

```sh
cp .env.example .env
# 编辑 .env 填入密钥与实际支持的模型/接口
node --env-file=.env server/index.js
```

也可由进程管理器注入上述环境变量。不配置密钥时，游戏仍能运行，生成按钮提示未开启；已有资产仍可预览和装备。模型必须支持 Responses API，默认模型名需在所用服务中可用。

生成使用异步任务接口，默认最多 2 个任务同时执行，150 秒超时；每 IP 每小时 6 次，提交间隔至少 15 秒，失败任务也占限额。当前 IP 取直接连接地址，经反向代理时所有玩家可能共享额度；上线时需结合可信代理和账号配额调整。限额是进程内状态，重启会重置，当前没有账号归属和跨实例配额。

`server/data/avatars/` 保存经过校验的 JSON 资产，部署时应挂载持久目录并备份；不可放入只读文件系统。房间快照只传资产编号，客户端按需获取结构。公开资产编号可供访问及装备，无私有角色权限。恢复默认不会删除资产；当前没有自动清理历史资产的机制。

本次本地验收记录见 `docs/verification-text-avatars.md`。不代表已更新线上服务器。
