# Saltline 自由混战实施方案

目标：复用原版港口、操控、枪械与音效，支持 2—4 人房间码联机，每局 300 秒，死亡 3 秒复活，服务器计算命中、弹药、比分和结算。

架构：原始 HTML 保持为来源副本；构建后的 HTML 仅替换单人游戏管理器，通过独立 client.js 接入 Node.js/WebSocket 房间服。地图碰撞体由固定种子 4207 的原版生成结果导出至 server/map.json，服务器不信任客户端上传的地图或伤害。服务器根据客户端操作输入计算位置、重力和碰撞，客户端预测与校正，远端插值；这一版不承诺竞技级反作弊或延迟回溯。

文件：public/index.html 原版渲染入口；public/client.js 联机适配、远端角色、房间和计分 UI；public/pvp.css DOM 样式；server/match.js 纯对局规则；server/index.js HTTP 与 WebSocket；server/map.json 固定地图；tests/match.test.js 规则测试；tests/network.test.js 真实双 socket 集成测试。
