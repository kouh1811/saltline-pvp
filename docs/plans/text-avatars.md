# 文字自定义角色实施计划

范围：把通用声明式角色接入正式游戏源码，提供纯文字生成、独立3D预览、手动装备、默认恢复和对其他玩家可见的外观；本地验证，暂不部署。

- [x] 服务端：原生Node模型调用、校验与一次结构修复；连接会话认证；异步作业、超时、并发和IP限额；不可变资产按需读取与磁盘保存。
- [x] 网络：玩家快照仅携带avatarId；装备由服务端确认，断线会话作业停止，既有对局规则和碰撞体不变。
- [x] 客户端：大厅/对局菜单入口、文字与状态、独立3D预览、确认装备/默认恢复、本地保留资产ID、异步远端加载与资源释放；无图片入口。
- [x] 验收：服务单元和真实双WebSocket测试；真实AI文字生成一次；双客户端装备、恢复与刷新、控制输入和错误回归；截图与部署配置说明。
