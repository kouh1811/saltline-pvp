# Saltline 管理后台设计

用户在对话中批准实施：单管理员、多个 API 配置、角色开关、生成记录、配置回退；复用 Node 服务和 /admin，SQLite 持久化，角色文件继续独立保存。本地测试，不自动部署线上。

## 行为

- API 配置包含名称、地址、协议 Responses/Chat Completions、模型、加密密钥。Key 不回传明文，留空保持，显式清除。成功通过真实结构生成测试后才允许启用变化的接口；连通性测试独立。
- 角色开关：总开关、文字生成、玩家预览、装备、对局中换装（默认关）；关闭预览只取消玩家 3D，不取消确认装备。总开关/资产禁用令在线使用者立即回退默认。
- 服务器执行权限限制，WebSocket 推送公共配置；任务保留提交时配置。新配置无需重启。配置带版本号，防止覆盖另一页的新编辑；历史回退生成新版本。
- 生成记录包含描述、模型/接口、状态、耗时、结果/错误、测试标记，保留天数可调。后台始终可以预览并禁用资产。概览显示实时在线/房间/任务以及近24小时统计。
- 管理员密码哈希、8小时内存会话、HttpOnly/SameSite Cookie、CSRF、登录限流。首次密码来自服务器 ADMIN_PASSWORD，首次成功初始化后以数据库为准；加密主密钥只由环境提供。缺失管理凭据时后台不开放，游戏兼容旧配置。
- SQLite 存储版本、密码哈希、测试指纹、任务、资产状态、操作记录；密钥 AES-256-GCM，数据库和侧文件不得提交。回退不恢复密码/已禁用资产/任务记录。

## 视觉与范围

窄侧栏与浅灰绿工作面，深墨绿文字，铜橙主操作，系统中文字体；状态紧邻具体配置，移动端单列。五页：概览、AI接口、角色设置、生成记录、系统设置。

第一版不含账号体系、永久玩家额度、自动接口切换、多服务器控制、付费、踢人和封禁。公网/生产部署另行处理。
