## 自动化

`npm test` 覆盖原有对战规则/物理/真实WebSocket，及：

- 密钥落盘加密、读取脱敏、重启持久化、留空保持、显式清除。
- 配置版本冲突、未经测试的新接口无法启用、回退创建新版本、记录保留清理。
- 两种模型协议、结构校验/修复、超时、取消、迟到结果不覆盖。
- 登录错误及限流、未初始化后台拒绝访问、CSRF/来源检查、密码更改撤销会话、过期和退出。
- 两客户端公共配置同步、禁用资产回退默认、服务端拒绝关闭功能/对局中直接生成和换装、恢复默认始终允许。
- 运行中任务保留旧接口，新任务使用新接口；操作记录与HTTP不包含测试密钥。
