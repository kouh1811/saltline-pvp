# 文字自定义角色本地验收

日期：2026-11-12。分支：codex/text-avatars。环境：macOS、Node、本地 localhost:18457、Ego Chromium；未部署线上，未推送 GitHub。

## 真实生成与双客户端

通过正式游戏页面输入：

> 铜绿色机械章鱼，八条自然卷曲的触手，浅色吸盘，琥珀色眼睛，带铆钉的分层装甲。保持章鱼体型，不要人形。

服务端实际请求模型，返回“铜潮八腕”，任务耗时 **36.1 秒**（单次观测，不能代表所有提示词速度）。资产 ID：44004ad24d857318e851290ed5f83255。第二客户端构建：36 个部件实例、560 个表面细节实例，约 10.4ms（一次本地观测）。

- 生成完成时，双客户端快照的 avatarId 仍为 null；没有自动装备。
- 点击装备，另一客户端按 ID 获取资产并构建角色，画面与预览来自同一份数据。
- 恢复默认：另一客户端移除自定义网格，重新显示默认人物。
- 再次装备并刷新后，重新创建房间，所选资产自动恢复。
- 在工坊打开期间开始对局，player.enabled=false；输入 W/R/C 和 Tab 后，noFire=true、弹药30、战绩未弹出。
- 390px 移动端模拟：文档宽390px、弹窗宽352px，没有横向溢出，可纵向滚动。

截图：`screenshots/text-avatars/preview.png`、`multiplayer.png`、`mobile.png`。多人截图采用测试相机靠近另一玩家，便于检查外观；没有替换角色、光照或地图。移动端为浏览器模拟，不代表真机验收。
