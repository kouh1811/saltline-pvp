# 验收记录 · 2026-11-12

环境：本机 macOS、Node.js v24.18.0、Chromium/Ego 浏览器，127.0.0.1。实际双浏览器页面使用同一房间服，不包含公网部署或物理手机验收。

## 已验证

- `npm test`：9 项通过，包括真实 WebSocket 双客户端创建/加入、房间隔离、断线离开、移动同步，以及真实网络消息触发击杀、等待 3 秒自然复活、结算和下一局。
- 规则测试：满员限制、非房主禁止开始、至少两人、射速限制、服务器弹药与重装、墙体遮挡、复活保护、比分、300 秒到期后停止计分、伪造位置不生效、服务器碰撞。
- 两个真实浏览器通过大厅按钮创建/加入同房，启动比赛；原地图、枪械、雨景加载，双方各有一个远端角色。
- 实际键盘按键移动，观察服务器位置和本地预测位置变化，双端同步。
- 使用仅绑定 127.0.0.1 的独立测试进程，将双方摆到真实地图的可见通道；实际鼠标开火使服务器确认 4 次命中，击杀者 1 击杀、目标 1 阵亡，目标显示复活倒计时并于 3 秒后恢复满血及操作。位置夹具不在正式服务器开放。
- 测试进程强制对局到期，两个页面显示结算；房主点击“再来一局”，双方进入第二局且分数清零。300 秒边界由规则测试验证，未人工等待完整 5 分钟。
- 正式启动入口最终复验：默认流畅画质、原版音频模块正常初始化、双方加入与开局、远端人数正确，页面错误记录为空。音效听感未单独验收。
- 390×844 移动视口大厅截图检查：无水平溢出，表单和按钮在屏幕内。这不代表物理手机触控操作已验收。
- `node --check public/client.js`、`node --check server/index.js`、`zsh -n 启动游戏.command` 通过。
